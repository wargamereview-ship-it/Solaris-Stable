# Fonts

Bundled so the game looks the same on any machine. All free to redistribute.

| File | Font | License |
|---|---|---|
| `FiraSans-*.ttf`, `FiraSansCondensed-*.ttf` | Fira Sans (Mozilla / Carrois) | SIL Open Font License 1.1, `FiraSans-OFL.txt` |
| `Hack-Regular.ttf` | Hack (monospace for record sheets and logs) | MIT / Bitstream Vera, `Hack-LICENSE.txt` |
| `FontAwesome.ttf` | Font Awesome 4 icons (from awesome-terminal-fonts) | SIL OFL 1.1 (font), MIT packaging, `FontAwesome-LICENSE.txt` |

The UI font falls back to Font Awesome, so any label can show an icon glyph (`UI.ic("wrench")`).
